# Badreads

## Project goal

The goal of the project is the creation of a library web application, which will be able to fetch information from an api, parse it and then display a book cover in a gallery that upon being clicked opens to a new page with the said books information.

The project is for my own personal use after it's finished and fully functional, though it might be made available as open source software depending on when it's finished.

## Project implementation

The project currently referred to as "Badreads" as a play on "Goodreads" will go through several distinct phases of development to aid me in learning to use java and other tech stack options such as databases or learning fullstack development

### Stage 1

The first from the app will take is a Command Line program which focuses on taking in a user inputted book ISBN through the scanner object.

Upon receiving the input it cleans the ISBN from any excess characters like spaces or dashes and then returns it to the main function from where it will be given to a HTTP request function by using parameters.
